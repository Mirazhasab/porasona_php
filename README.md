# porasona_php

A PHP project configured for both localhost development and cPanel deployment.

## Getting Started

For detailed setup instructions for localhost and cPanel, please see [SETUP.md](SETUP.md).

## Project Structure

- `.env.example` - Template for environment configuration
- `.htaccess.example` - Template for Apache server configuration
- `SETUP.md` - Detailed setup instructions

## Note

The `.env` and `.htaccess` files are excluded from version control to allow different configurations for localhost and cPanel environments.
